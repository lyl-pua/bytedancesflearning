# 临时演示：把本机 DeerFlow 暴露到公网（SSH 隧道法）

> 适用场景：你已经本机跑起了 DeerFlow（3000 + 8001），想**几分钟内**生成一个公网链接发给别人，让对方在自己手机/电脑上直接打开。
> 不需要注册账号、不需要装新工具（Windows 自带 `ssh.exe`）、不需要买服务器。
> 唯一代价：**本机不能关机、不能断网、那个开隧道的 PowerShell 窗口不能关**。

---

## 0. 先确认两件事

```powershell
# ① DeerFlow 前端和后端都还活着（本机 PowerShell 跑）
curl.exe -s http://127.0.0.1:3000/api/v1/auth/setup-status
# 期望返回：{"needs_setup":false,"registration_enabled":true}

curl.exe -s http://127.0.0.1:8001/health
# 期望返回：{"status":"healthy","service":"deer-flow-gateway"}

# ② 本机能连上 localhost.run 的 SSH 服务器（22 端口不能被运营商/防火墙拦）
ssh.exe -o StrictHostKeyChecking=no -T nokey@localhost.run
# 第一次会提示 "Permanently added"，接着打印欢迎语，说明 22 端口通
```

如果第 ② 步卡在那不动或超时，说明 22 端口被封，跳到下面「备选方案」。

---

## 1. 开一个独立的 PowerShell 窗口（**跟启动前后端的窗口分开**）

```powershell
ssh -o StrictHostKeyChecking=no -o ServerAliveInterval=5 -R 80:localhost:3000 nokey@localhost.run
```

等 **3~5 秒**，它会打印：

```
xxx.lhr.life tunneled with tls termination, https://xxx.lhr.life
Open your tunnel address on your mobile with this QR:
[QR码]
```

那行 `https://xxx.lhr.life` 就是**可以发给对方的公网链接**。复制出来就行。

> `ServerAliveInterval=5` 表示每 5 秒给服务器发个心跳包，防止 NAT/防火墙把连接掐掉。
> `-R 80:localhost:3000` 翻译：告诉 localhost.run 公网服务器，把别人访问它 80 端口的请求，反向转发到我本机的 3000 端口（DeerFlow 前端）。

---

## 2. 告诉对方怎么用

把链接直接发过去，对方打开就是你本机正在跑的 DeerFlow 登录页。

- 管理员账号：`student@example.com`
- 密码：`DeerFlow123!`

登录后正常聊天、正常用工具。

---

## 3. 用完了 / 要关了

那个 PowerShell 窗口里按 `Ctrl+C`，或者直接关掉窗口。隧道立即断开，链接失效。

---

## 4. 可能遇到的问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `ssh` 命令打印 URL 后 PowerShell 卡死 | 正常！隧道进程要一直跑，**那个窗口就不能关** | 新开第二个窗口继续干活 |
| 对方打开链接是 502 / "no tunnel" | 你本机的隧道进程已经死了（Trae 沙箱/系统清理/断网） | 回到第 1 步重新跑 |
| 链接打不开，对方看到「连接超时」 | 你本机断网了，或者 3000/8001 端口没在监听 | `curl 127.0.0.1:3000/api/v1/auth/setup-status` 再确认 |
| 第一次跑提示 `Permission denied (publickey)` | localhost.run 偶发要求密钥 | 备选 1：`ssh-keygen -t ed25519` 生成密钥再跑；备选 2：换 cloudflared（见下） |

---

## 5. 备选方案（SSH 不通时用）

### 备选 1：cloudflared（走 Cloudflare 网络，不需要 22 端口）

需要 Node.js（你装过 pnpm 就有）：

```powershell
# 不需要全局安装，npx 会自动下载
npx.cmd -y cloudflared tunnel --url http://localhost:3000 --no-autoupdate
```

等几秒，它打印 `https://xxxx.trycloudflare.com` 就可以发了。

cloudflared 比 localhost.run 偶尔会多出一层「你是人类吗」的验证页（tarpit），但链接稳定度更好。

### 备选 2：ngrok（需要免费账号）

去 https://ngrok.com 注册，拿到 authtoken，然后：

```powershell
ngrok config add-authtoken 你的token
ngrok http 3000
```

会吐一个 `https://xxxx.ngrok-free.app` 的链接。免费版每次重启 URL 都会变。

### 三者对比

| 工具 | 需要注册 | 需要装东西 | 链接稳定性 | 体验 |
|---|---|---|---|---|
| localhost.run | ❌ | ❌（ssh.exe 自带） | 中（偶发 IP 变） | 最简、无验证页 |
| cloudflared quick tunnel | ❌ | ✅（npx 下载） | 好 | 偶尔 tarpit 验证 |
| ngrok free | ✅ | ✅ | 中 | 稳定，但要账号 |

---

## 6. 安全提醒（务必看一眼）

1. **这条链接对任何人开放**——拿到链接的人可以：登录你的 DeerFlow、发送消息、**让 Agent 调用工具、访问你的沙箱文件**（`backend/.deer-flow/` 下的数据）。
2. **对方用的是你的 DeepSeek 密钥**——对话会持续消耗 token（每分钟 8~15k token 是正常的）。
3. **用完就关**（`Ctrl+C`），或者把密钥从 .env 里删掉重新启动。
4. 如果要**带登录保护**的临时链接，Cloudflare 提供「一次链接」模式（`cloudflared access`），需要 Cloudflare 免费账号。

---

## 7. 如果想长期稳定（不是临时演示）

本机方案始终受「关机就断」的限制。想永久在线的话，官方路线是买一台云服务器（腾讯云轻量 2 核 4G，≈60 元/月），仓库自带 Docker Compose 一键部署：

```bash
git clone --depth 1 https://github.com/bytedance/deer-flow /opt/deer-flow
cd /opt/deer-flow
cp config.example.yaml config.yaml   # 填上模型密钥
cp .env.example .env
docker compose -f docker/docker-compose.yaml up -d --build
```

部署完有固定 IP + 可配域名 + HTTPS，任何人任何时候都能打开。
